  • Aug 8, 2026 Behavior & Points Tracker. Graduated off the ideas backlog. An activity feed shows the recent log; “Archive Day & Reset” snapshots the day’s totals into an expandable history list and zeroes everyone back to 0, so points can reset daily or run all week, whichever a section needs. Prints a clean report of the current live totals. Multiple named sections, and can load a roster saved in the Name Picker.
