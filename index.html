The serverless answer is manual signaling — Classroom Timer's new “Mirror to a device” shows a QR code containing the connection offer, the other device (open classroom-timer/mirror.html, or scan it directly) scans it and shows an answer code back, camera-to-camera or copy/pasted by hand either way.
