Blank Map Generator — Enhancement Ideas

Already built and continuously extended — this is the wish list of further enhancements collected since. Improvements to an existing tool, not a new standalone tool.

Upload your own map imageEnhancement Let a teacher use a scanned or custom map file directly, bypassing Wikimedia Commons entirely, for district-specific or textbook maps that aren’t on Commons.
Answer-key / student-blank export modeEnhancement A toggle that hides label and legend caption text for a printable student handout, while a labeled version stays available as the teacher’s answer key.
Per-label text stylingEnhancement Bold/italic, font size, and color per label, matching the color/size control markers already got.
Numbered pin modeEnhancement Auto-number markers (1, 2, 3…) instead of icons, matching a numbered worksheet or answer key format.
Auto-computed scale barEnhancement Once a map is calibrated, show a real-world distance scale bar (e.g. "500 km") computed from the projection math.
Accessibility hatching for regions/linesEnhancement Optional hatch/pattern fills as an alternative or addition to color, so shaded regions and lines stay distinguishable for colorblind students.
Batch marker placement from coordinatesEnhancement Paste a "name, lat, lon" list and auto-place matching markers at once on a calibrated map, instead of clicking each one by hand.
Keyboard nudge + legend reorderingEnhancement Arrow-key nudge for a selected label/marker’s position, and drag-to-reorder legend rows instead of first-placed-first-listed order.
Multi-page tiled printEnhancement Print a heavily zoomed-in, detailed map across multiple tiled pages (poster-style) instead of squeezing it onto one sheet.
Full undo/redo historyEnhancement Broaden the current "undo the last delete" into a real undo/redo stack covering moves and edits too, not just deletions.
Source of truth for this list is /IDEAS_BACKLOG.md in the repo. See something missing, or want to call dibs on building one? Email @dsmoore.
