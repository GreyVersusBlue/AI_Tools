Platform-Wide — Big Swings

Cross-cutting infrastructure, not new standalone tools — these would touch the landing page or several existing tools at once instead of adding one new page. All still within GitHub Pages’ static-hosting limits (no server, no accounts, no database) — several just lean on browser APIs the toolkit doesn’t use yet.

Cross-Tool Shareable State LinksIdea Encode a tool’s current board (a seating chart, a bracket, a rubric) into the page URL itself, so pasting a link opens that exact state on another screen — no server, no login, just a longer link.
Live Student-View SyncIdea Peer-to-peer (WebRTC, no server) mirroring of Review Game Board scores, Bracket picks, or the Classroom Timer onto students’ own devices, not just the projector.
