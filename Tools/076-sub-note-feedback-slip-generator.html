Sub Note / Feedback Slip Generator

A quick slip for a substitute to fill out by hand before they leave for the day.

Each saved slip keeps its own prompts, copy count, class or period and “call me” box, so a general slip, a lab-day slip and a testing-day slip can all be ready at once. + New uses the starter above; Duplicate copies the slip on screen.

A prominent checkbox the sub ticks when something needs your attention — so you can triage which slips to read first from a stack.

Prompts

Edit, remove, or add prompts — each gets a blank line for the sub to write on.
