Backup & Restore

Export everything — blueprint, student groups, and settings — into a single JSON file you can back up or move to another computer. Importing replaces the entire current project.

Hand Off to Another Device

Send the current full project straight to another laptop over the same Wi-Fi — a QR/code pairing, same idea as Classroom Timer's "Mirror to a device" — instead of exporting a file and importing it there by hand.

Project Snapshots

Save up to 5 named copies of your project to browser storage. Snapshots are independent of exported JSON files and stay in this browser.

Automatic Recovery Points

Kept on their own, without you asking: the whole project is copied every few minutes while you work, and again when you leave the page. Three are held at a time, oldest dropped. If the browser dies, or the saved layout comes back unreadable, you'll be offered the newest one on the next open. These live in this browser's IndexedDB, separate from the auto-save above, so a full-storage failure can't take both.

⚠ Danger Zone

Help & Tips
The workflow
1
Blueprint
Draw classrooms, hallways, and staircases. Pair staircases to teleport between disconnected sections. Right-click a tile for quick actions.
2
Rooms
Select a classroom and assign a unique room number. Room numbers must be unique across the building.
3
Schedules
Add groups, set a grade, and choose a destination room for each period. Set the number of periods in Settings.
4
Visualize
Choose Single, Comparison (up to 4), By Grade, or All. Busier hallways shift from green toward red.
