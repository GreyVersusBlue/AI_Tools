Page shape
Sets the shape of the preview below, and of everything Print / Save PDF / Download PNG produce.

Map coordinates

Sets the real-world latitude/longitude of this map's edges. Pick whichever projection this map was drawn in below — most Commons "blank map" files use one of these two. Readings will still drift for maps drawn in other projections (Robinson, conic, etc.).

Batch place markers from coordinates

Paste one place per line as name, latitude, longitude (e.g. Paris, 48.8566, 2.3522). Requires the map's coordinates to be set first (see “Set Map Coordinates…” above). Each line places a marker — using whichever marker style/color/size is currently selected above — plus a text label with its name.

Label sets

Drops a whole list of places onto this map at once, at their real coordinates — so the 13 colonies, the 50 states, or the countries of Europe don't have to be typed out again for every new map. Requires the map's coordinates to be set first (see “Set Map Coordinates…” above). The built-in coordinates are approximate label anchors, not survey points: expect to drag a few.

Numbered worksheet & answer key

Turns this map into the standard social-studies labeling worksheet: every text label on the map — and every numbered marker whose key caption holds its answer — becomes a numbered item, with a numbered answer line for each one beside or below the map, an optional shuffled word bank, and a matching answer key. Ask for more than one version and each gets its own numbering and word-bank order — one map, a whole set of non-copyable papers.

Tiled poster print

Prints exactly the region you're currently panned/zoomed into, split across multiple full-size pages at full print resolution — good for a heavily zoomed-in, detailed map that would lose detail squeezed onto one sheet. Pages overlap slightly at their edges to make lining them up and taping them together easier. A final page prints the key. (The compass rose and scale bar print on page 1 if enabled; the locator inset doesn't apply to a tiled poster and is skipped.)
