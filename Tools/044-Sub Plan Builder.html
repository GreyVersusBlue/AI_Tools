  Good to know
  
    
    
  • Everything in "Standing details" is saved only in this browser (localStorage) — it won't sync to another computer.
    • 
    
  • Use **text** in any of the note fields to bold that part in the exported document.
    • 
    
  • The Student Notes box is intentionally never saved — refreshing the page clears it. The attached seating chart image works the same way.
    • 
    
  • The generated Word doc includes a real header/footer with page numbers, and period-by-period info as an actual table — not just a plain-text copy for the quick text copy view.
    • 
    
  • No student names or other data are sent anywhere — the Word doc is built entirely in your browser.
    • 
    
  • "Days out" counts school days only — weekends are skipped automatically, so 3 days out starting Friday means Friday, Monday, and Tuesday.
    • 
    
  • The Sub Binder Generator reads whichever dates you've selected here to default its own date picker — no need to re-enter the date there.
