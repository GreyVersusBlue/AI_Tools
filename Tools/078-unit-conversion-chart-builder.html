Pick the unit sets you need, tweak the list, print a one-page reference chart.

Unit sets to include

One click checks the right sets for the grade band — elementary gets the within-system basics plus time; middle school adds cross-system conversions and temperature formulas. Fine-tune with the checkboxes after.

Print layout

Fewer unit sets read better in 1–2 columns; a full chart with several sets fits more on one page in 3.

Chart preview
