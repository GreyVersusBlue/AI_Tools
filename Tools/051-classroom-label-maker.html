Classroom Label Maker (Target Language)

Label real objects in the target language — each with a QR code that speaks the word aloud.

⚠ This page is currently open from a local file, not the live site. QR codes printed now will encode a file:// link that won’t work when scanned by a phone. Open this tool from its real web address before printing labels for classroom use.

Each list keeps its own words and language, so a room set, a kitchen set, and a unit set can coexist — switching lists never overwrites another.

The QR code's pronunciation page only works when this site is opened from its live hosted address (not a local file) — the phone scanning the code needs a real web address to reach.
