Blocked-storage check

Chrome with site data blocked does not make localStorage.setItem fail — it makes reading the localStorage property itself throw. None of the Name Picker's old forty-six call sites survived that, and it is the case gvb-save's memory fallback exists for. Chrome's site settings cannot be driven from a test script, so this page installs the same failure by replacing the property with a throwing getter before importing the store.

Open it and read the table. Everything should say PASS.
