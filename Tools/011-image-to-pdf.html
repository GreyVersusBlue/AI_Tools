Combine photos and images into a single PDF — runs entirely in your browser

Accepts .png, .jpg/.jpeg, .webp, .svg, and .pdf · No file size limit
A PDF is turned into one picture per page (up to 100 pages, drawn about 1600 px wide), so each page can be reordered, rotated, removed or merged with other files. A PDF with more than one page asks which pages to add first. Its text becomes part of the picture and can no longer be selected or searched, unless you tick “Make the PDF searchable” below.
2 · Sort & Layout Options

Reads the printed words on each page and hides them under the picture, so the PDF can be searched and its text copied. The pictures stay exactly as they are. English only; handwriting is not read, and a few words will be misread. It takes a few seconds a page. The first time you use it, it downloads the reading files (about 7 MB), so it needs an internet connection that once. After that it works offline on this device, until the toolkit next updates. The pictures never leave your computer.

A phone photo of a whiteboard is grey, unevenly lit, and expensive to print. This flattens the lighting across the image, sets the board or paper to white, and pushes the writing dark. It runs on your machine like everything else here — nothing is uploaded.

Add an optional caption to print under an image — useful for documentation packets and lab photo series.

Scan finds the sheet in a photo of a page, pulls it flat and upright, and evens out the light and the shadows. Each row's Scan button opens the photo so you can move the four corners yourself; Scan all does it for the photos not yet scanned and shows each page in a strip with the corners it found drawn on it, and marks the ones it was not sure of “Check the corners”; press a picture in the strip to open it. A scanned page is saved as an image (black and white as a PNG), so its text is not selectable. A scan is kept only until you leave or reload this page.

Drag a thumbnail to reorder it, or use the arrows on it (arrows work on a phone).
    6 · Student Portfolios (optional)

    Parses a student's name out of each filename, builds every student's images (in the sort order above) into their own PDF using all the layout/quality/header options above, then bundles every student's PDF into one .zip. Put {student} in the title-page Title or Subtitle above to have it replaced by each student's actual name.

    Naming convention: everything up to the last run of digits (and an optional word right before them, like "pg", "photo", or "scan") is taken as the student's name; underscores and hyphens become spaces. Maria_Diaz_04.jpg → "Maria Diaz". Files that don't parse to a name — a camera default like IMG_0421.jpg, or a bare number — are grouped into a single "Unsorted" PDF instead of being dropped. Names that run two people together with no separator (e.g. SmithJohn_2.jpg) come out as one token — there's no way to guess where to split it.
