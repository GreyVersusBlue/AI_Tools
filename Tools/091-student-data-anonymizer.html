Student Data Anonymizer

Replace every student's name and ID with a code, keep the rest of the file, and save a key that turns the codes back into names.

Nothing leaves this computer. Files are read here, in this tab. Nothing is uploaded, and nothing is saved: close the tab and it is all gone. The page only sees an old key when you choose one.

1. Choose the files

PDF, CSV, XLS or XLSX. Read so far: ESP Reporting Center attendance totals, Performance Matters baseball cards and assessment results, and Teacher Access Center Student Detail Reports (PDF). Other spreadsheets work too: check the columns it picks. Choose several files at once and a student gets the same code in all of them.
A key this page saved before. A student it already lists keeps their code; anyone new gets a new one, and the key you save adds them.

2. What was found

    3. Student details to keep

    Names and IDs are always replaced by the code, and teacher names, courses and scores are always kept. Everything below is about the student and is removed unless you tick it: keep only what you are analyzing.

    Check the columns

    How each column was read. Change one if it is wrong: a column holding a student's name or ID must say so, or it will be copied as it is.

    4. Save

    Keep the key somewhere safe. It lists every student by name next to their code, so it is the one file that is not anonymous. Without it the codes cannot be turned back into names.

    Put names back

    Choose an anonymized spreadsheet and the key it was made with. You get the same file with a Student ID and a Student Name column in front of the codes.

    CSV, XLS or XLSX. A PDF this page saved is for reading; put names back into the Excel copy.
