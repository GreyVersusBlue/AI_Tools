Cognates & False Friends Reference List Builder

Build a reference list of look-alike words that mean the same thing, and ones that don't.

Bulk paste import

One entry per line, fields separated by tabs, pipes, or commas (a spreadsheet paste works). Two fields — word | English — adds a true cognate. Three fields — word | looks like | actually means — adds a false friend. Or name the type yourself as a last field: cognate or false. Entries are added to the lists below without replacing anything.
